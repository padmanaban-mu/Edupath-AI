UI/UX Designer Track — India

Designing for the next billion users. From simplifying UPI payments to creating accessible EdTech for rural India, learn to build human-centric experiences that balance beauty with business goals.

Role in the Indian Context

In India, designers must solve for diversity. You will design "Lite" apps for low-bandwidth areas, optimize interfaces for 22+ regional languages, and create trust-based flows for the growing digital-first population.

Roadmap: UX Research vs. UI Design

Phase 1: Foundations & Research (Month 1-2)

UX Research

Learn User Personas, Empathy Mapping, & User Flows. Conduct real interviews with diverse Indian user groups.

Design Principles

Master Typography, Color Theory, & Grids. Understand the 8pt system used in modern app development.

Phase 2: Prototyping & Systems (Month 3-4)

High-Fidelity UI

Master Figma. Learn Components, Auto Layout, and Variants to build scalable Design Systems.

Prototyping

Build Interactive Prototypes. Use micro-interactions to make apps feel responsive and alive.

Phase 3: Portfolio & Handoff (Month 5-6)

Portfolio Building

Create 3 **Case Studies** on Behance or a personal site. Focus on solving a real problem (e.g., Healthcare or Finance).

Dev Handoff

Learn to use Zeplin or Figma Inspect. Understand basic CSS to communicate better with developers.

High-Demand Tools

Figma Adobe XD / Sketch Miro (Research) Protopie Adobe Illustrator
